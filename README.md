# VPN Automator

Android-приложение (minSdk 28 / Android 9+), автоматически управляющее
OpenVPN-подключением в зависимости от текущей сети.

## Возможности

- Подключение / отключение VPN при входе в Wi-Fi с заданным SSID.
- Подключение / отключение VPN при переходе на мобильную сеть
  (действие выбирает пользователь).
- Принудительное отключение VPN при потере любой сети.
- Автоматический запуск сервиса после перезагрузки.
- Работает через OpenVPN for Android (`de.blinkt.openvpn`).

## Сборка

### Локально

    gradle :app:assembleDebug

### Через GitHub Actions

Просто запушьте репозиторий в ветку `main` — сборка запустится автоматически.
APK появится в разделе **Actions → Build APK → Artifacts**.

### Публикация релиза

    git tag v1.0.0
    git push origin v1.0.0

APK будет прикреплён к GitHub Release.

## Установка

    adb install vpnautomator-debug-<sha>.apk

## Первый запуск

1. Установите **OpenVPN for Android** (ссылка в приложении).
2. Импортируйте `.ovpn` в OpenVPN for Android, задайте имя профиля.
3. В нашем приложении введите то же имя профиля и загрузите `.ovpn` для справки.
4. Настройте правила Wi-Fi и поведение для мобильной сети.
5. Нажмите «Запустить мониторинг».
6. **Разрешите «Отображение поверх других приложений»** в системных настройках —
   это требуется Android 10+ для запуска активности OpenVPN из фона.

## Ограничения

- Требуется установленный OpenVPN for Android.
- Для получения SSID нужно разрешение на геолокацию (Android 10+).
- Для управления VPN из фона нужно разрешение SYSTEM_ALERT_WINDOW.
